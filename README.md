# 🤖 Landing Page - Inteligência Artificial

Uma **landing page moderna** sobre **Inteligência Artificial**, desenvolvida para apresentar conceitos, aplicações e impactos da IA de forma clara, visual e interativa.

---

## 🚀 Sobre o Projeto

Este projeto foi criado com o objetivo de explicar a **Inteligência Artificial** de maneira simples e acessível, abordando:

* 📌 O que é IA
* ⚙️ Como funciona
* 🌎 Aplicações no mundo real
* 🤖 IA Generativa
* ⚖️ Ética na IA
* 🔮 O futuro da tecnologia

A proposta é oferecer uma experiência visual fluida em uma única página, com navegação simples e intuitiva.

---

## 🧠 Tecnologias Utilizadas

* HTML5
* CSS3
* Google Fonts
* Design responsivo

---

## ✨ Funcionalidades

* 📱 Layout responsivo (adaptável a diferentes telas)
* 🎯 Navegação em uma única página
* 🎨 Interface moderna e organizada
* 🖼️ Uso de imagens ilustrativas para facilitar o entendimento
* ⚡ Estrutura leve e rápida

## 🖥️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/Ellensramalho/One-Page-Inteligencia-Artificial
```

2. Acesse a pasta:

```bash
cd One-Page-Inteligencia-Artificial
```

3. Abra o arquivo `index.html` no navegador.
